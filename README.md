# SQE Library Management System

A library management system built as part of the Software Quality Engineering (SQE) course. 
This project handles book management, member management, and book search functionality, 
following SQE best practices including testing, CI/CD, and documentation.

## Features
- Book Management (add, update, delete, view books)
- Member Management (register, update, remove members)
- Book Search (search by title, author, ISBN, etc.)

## Project Structure
- `src/` - source code
- `tests/` - unit and integration tests
- `docs/` - documentation
- `screenshots/` - UI screenshots
- `.github/workflows/` - CI/CD workflows
